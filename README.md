# Mr. D. — Gestão de Clientes e Documentos

Aplicativo gratuito para Windows, desenvolvido para organizar a rotina do despachante: clientes, acervo, documentos em PDF, serviços, protocolos e alertas de vencimento.

**Site:** https://mrd-app.pages.dev/

## Download

[Baixar Mr. D. 1.0.0 para Windows 64 bits](https://github.com/mrd-app/mrd-downloads/releases/download/1.0.0/MrD-Setup-1.0.0-win-x64.exe)

## Requisitos

- Windows 10 ou Windows 11 de 64 bits.
- 32 GB de espaço livre recomendados.
- Internet para baixar o instalador; o uso do aplicativo é offline.

## Instalação

1. Baixe o arquivo `MrD-Setup-1.0.0-win-x64.exe` pelo link acima.
2. Execute o instalador e siga as instruções na tela.
3. No primeiro acesso, configure os dados do despachante, usuário e senha.
4. Guarde sua chave de recuperação em local seguro.

## Funcionalidades

- Cadastro de clientes, atividades e até dois endereços.
- Acervo vinculado ao titular e histórico de titularidade.
- Controle de CR, autorizações, CRAF, GT e outros documentos.
- Importação e classificação manual de PDFs e leitor integrado.
- Acompanhamento de serviços, protocolos e andamentos.
- Alertas de vencimento e registro dos avisos enviados.
- Exportação da ficha do cliente em PDF, com acervo atual opcional.
- Login, bloqueio por inatividade e criptografia dos dados e PDFs.
- Backup e restauração dos registros e PDFs em um único arquivo.

## Cuidados Com Seus Dados

Faça backups regulares, mantenha uma cópia em outro dispositivo e teste a restauração. Guarde a chave de recuperação separada do computador. Antes de atualizar uma instalação existente, faça um backup.

## Sobre Este Repositório

Este repositório é utilizado para distribuir instaladores. O aplicativo é gratuito e seu código-fonte é fechado. Os arquivos automáticos **Source code** do GitHub contêm apenas os arquivos deste repositório, não o código-fonte do Mr. D.

O Mr. D. é um aplicativo independente, sem vínculo institucional com órgãos governamentais. Ele organiza e acompanha informações; não realiza automaticamente solicitações nos sistemas oficiais.
